# 用记忆代次和删除屏障收敛清空竞争

状态为 accepted。清空时可能已有普通任务、显式创建或上游迟到请求正在写入。按用户与提供方建立单调记忆代次，清空先提升代次、暂停该范围记忆读写并取消旧排队任务，旧生成结束时抑制旧代次任务。

所有已发出的旧副作用需要核验，确认收敛后最终清空提供方，再解除屏障。未知上游结果保持待确认并告警。该选择增加操作状态、远程关联及恢复处理，但使清空完成能表示实际外部结果。本地租约隔离状态提交，远程副作用依靠供应商幂等能力、结果核验与最终清空收敛。

会话和用户删除共享这套原则，先阻止业务访问，再异步清理并保留最小远程映射。历史记忆引用标记删除，原始记录遵守会话及用户删除。备份恢复须重放删除和代次记录后恢复写入，供应商核验能力是部署验收的一部分。
