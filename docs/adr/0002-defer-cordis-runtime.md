# 首版延后引入 Cordis

状态为 superseded by [ADR-0007](0007-unified-single-process-backend.md)（2026 年 11 月 25 日起项目明确放弃插件运行时路线，不再保留 Cordis 引入计划）。

原决策：首版不使用 Cordis。项目先使用普通依赖注入和显式的模块装配来实现模型、记忆和人设的可替换性。Cordis 保留为未来的可选运行时装配层，在系统需要插件运行时加载和卸载、插件依赖管理、第三方插件生态或多 Agent 组合时再引入。

这个决定避免让对话内核绑定插件运行时，同时保留未来把现有提供方适配器装配为 Cordis 插件的可能。Cordis 如果被引入，只位于启动和装配层，不能成为领域接口或对话流程的隐式依赖。
