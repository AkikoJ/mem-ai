# 将长期记忆视为对话记录的派生数据

状态为 accepted。PostgreSQL 保存用户、Agent、会话、人设版本、消息和模型配置等应用主数据。长期记忆由 `MemoryProvider` 管理，并从完整对话回合或用户明确指令中生成。MemOS 是可替换的记忆实现，不作为应用原始对话记录的唯一来源。

这个决定支持用户查看、纠正和删除记忆。普通对话的记忆写入通过持久化任务异步执行，显式创建在确认成功后同步返回，删除与清空通过可查询操作表达实际进度。

2026 年 11 月 20 日补充删除约束。基于历史记录重建记忆需显式触发并遵守记忆代次、删除标记与用户当前意图，相关边界见 [记忆清空屏障决策](0005-memory-epochs-and-deletion-barriers.md)。
