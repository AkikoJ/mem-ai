# 采用模块化单体和提供方接口

状态为 accepted。Mem-AI 首版采用模块化单体，并通过 `ModelProvider`、`MemoryProvider` 和 `PersonaProvider` 隔离模型、记忆和人设实现。API 与 Worker 使用独立进程入口并共享业务模块和 PostgreSQL，降低部署和调试成本，同时保留替换实现和未来拆分服务的接缝。对话内核只依赖项目自己的稳定接口，不直接依赖 MemOS、具体模型供应商或具体数据库。

我们考虑过直接按模型、记忆和人设拆成多个独立服务，但首版的独立部署需求尚未成立。过早拆分会引入网络失败、鉴权、重试和部署协调成本。只有在多个应用共享能力、需要独立扩容或需要独立权限边界时，才把提供方替换为远程适配器。
